# pcb-detector 가중치

`weights/best.pt` = PCB 결함 모델 v2 (10/25 교체). YOLO11s, imgsz 640. 클래스 순서는 옛 모델과 같아서 `mcp_server.py`는 그대로 쓴다.

| 평가 (PKU `l_light_*` test 281장, conf 0.25) | 옛 모델 | v2 |
|---|---|---|
| 클래스 회수율 합계 | 162/281 (58%) | 266/281 (95%) |
| mAP50 | 0.515 | 0.938 |
| 정상 PCB 2장·흐린 사진 오탐 | 0 | 0 |

- 학습 데이터: PKU PCB 결함 타일 (Kaggle `norbertelter/pcb-defect-dataset`, 연구 공개용) + DsPCBSD+ (CC BY 4.0, Lv et al. 2024, 우리 6클래스로 바꿀 수 있는 5,119장)
- 누수 차단: 평가 사진의 원본 보드 사진은 회전·반전 변형까지 학습에서 전부 뺐다 (옛 분할은 평가 사진 278/281장의 변형본이 학습에 섞여 있었음)
- 한계: 3 epoch만 학습 (메모리 부족). 평가 보드가 학습 보드와 같은 종류라 처음 보는 보드 성능은 미확인. 보드 전체를 멀리서 찍은 사진은 결함이 작아 놓칠 수 있다
- 학습 스크립트·원본 숫자: `04_캡스톤_고도화/작업/pcb_v2/` (레포 밖)
