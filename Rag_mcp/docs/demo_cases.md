# 가상 수리 사례 60건

세탁기 20건 · 에어컨 20건 · 기타 가전 20건. 전부 팀 시연용 가상 자료이며 실제 제조사 수리 이력이나 검증된 수리 절차가 아니다.

- 저장 원본: `data/demo_confirmed_cases.json`
- 검색 결과: `is_demo=true`, `source_type=synthetic_demo_repair`, `가상 확정 사례 (데모)` 표시
- 기존 청소기 공개 사례 2,711건은 변경하지 않는다.
- `other`는 명시적인 기타 제품 분류다. 제품 미확인을 뜻하는 `unknown`으로 검색하면 사례 검색을 생략한다.
- 기타 가전 요청의 원문에는 냉장고·식기세척기 같은 실제 제품명을 포함한다.
- 사진 모델 라벨은 사례에 확인된 검출 정답으로 저장하지 않는다. 일부 가상 소견에 라벨 후보와 후속 점검 결과를 서술했다.

## 검색에 추가하기

로컬 Qdrant 파일을 중복으로 열지 않도록 8014 RAG 서버를 먼저 종료한 뒤 같은 환경에서 실행한다.

```bash
cd Rag_mcp
env -u OPENAI_API_KEY uv run --env-file ../.env repair-mcp seed-demo-cases
```

반복 실행은 기존 보고서를 중복 추가하지 않는다. 이후 RAG 서버를 재시작한다.

## 연동 범위

RAG MCP와 Python AI 입력은 `other`를 지원한다. Spring의 현재 `ProductTypes`는 아직 세 제품만 변환하므로, 화면에서 기타 가전을 접수하려면 백엔드 담당자가 `other`를 전달하도록 별도로 연동해야 한다. 해당 백엔드 코드는 이 변경에서 수정하지 않았다.
