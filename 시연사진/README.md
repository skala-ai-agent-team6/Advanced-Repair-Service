4. `field-tech / 1234` 로그인 → 오늘(또는 다가오는 방문) → 방문 준비 리포트: 고장 위치 박스·원인·준비 부품·공구 4개·보증

## 가전별/ (다른 가전으로 시연할 때)
- 접수 화면에서 제품 종류를 바꾸고, [제품 전체] 칸에 `*_전체_*`, [고장 난 부분] 칸·추가에 `*_부품_*`를 올린다
- 세탁기: 전체(긁힘·녹·찌그러짐) / 부품(드럼·보풀필터·거름망·통 하부·세제함)
- 로봇청소기: 전체 위 / 바닥 / 부품(바퀴 모듈·모터 분해)
- 에어컨: 실내기·실외기(찌그러짐) / 부품(필터 오염)

## 코드합성/ (부품 결함 합성 사진, 정답 박스 `labels.json`)
