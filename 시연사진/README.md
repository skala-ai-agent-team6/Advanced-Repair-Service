# 시연사진 넣는 순서

## 1. 기판 (접수 첫 사진)
1. `1_흐린 PCB기판.jpg`를 넣는다 → AI가 "흐리다, 다시 찍어 달라"고 요청
2. 요청이 뜨면 `1-2_명확한 PCB기판.jpg`로 바꿔 넣는다 → 기판 결함 검출

## 2. 기계 (세탁기 추천)
1. `2_세탁기_전체.jpg`를 넣는다 → AI가 부품 사진을 추가로 요청
2. 요청이 뜨면 `2_1세탁기_부품.jpg`를 넣는다 → 녹·긁힘·찌그러짐 검출

다른 가전도 순서는 같다 (전체 → 요청 뜨면 부품)
- 에어컨: `2_에어컨_전체.jpg` → `2_에어컨_부품.jpg`
- 로봇청소기: `2 로봇청소기_전체.jpg` → `2_1 로봇청소기_부품.jpg`
