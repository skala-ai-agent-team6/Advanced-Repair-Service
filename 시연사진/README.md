# 고객 시연 사진

1. `localhost:5173/service/request` → 값은 미리 채워져 있음. 사진에 **1, 2번** 올리고 접수
2. [접수 내역 조회] → "흐리거나 어두운 사진" 안내 → **3번**으로 [다시 올리기] (대체)
3. 잠시 뒤 "사진이 더 필요해요" → **4번**으로 [사진 추가하기] (추가)
4. 진단 완료 → `field-tech / 1234`로 로그인해서 출장 일정·리포트 확인
